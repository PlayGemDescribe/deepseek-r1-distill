# DeepSeek-R1 Distill

### Open-source reasoning model with chain-of-thought

DeepSeek-R1 Distill brings powerful reasoning capabilities to local hardware. This distilled model delivers transparent, step-by-step thinking across math, coding, and logic tasks — fully open weights, no API required.
